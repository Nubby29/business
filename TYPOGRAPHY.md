# Typography

## Primary typeface
Use the system UI stack for the first production website so the site loads without an external font dependency:

Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

## Hierarchy
- Display: large, tight, bold headlines with strong negative tracking.
- H2: compact section headlines.
- H3: semibold card/service titles.
- Body: comfortable line-height for business readers.
- Metadata: small, muted, uppercase or compact labels.

## Principles
Prefer fewer font sizes with a clear hierarchy. Use weight to establish importance instead of excessive decoration. Keep paragraphs readable and avoid long line lengths.
