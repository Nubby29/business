# Brand Color System

## Core palette

| Token | Hex | Use |
|---|---|---|
| Ink 950 | #0B1220 | Primary headings, navigation, dark surfaces |
| Ink 800 | #182338 | Primary buttons and strong text |
| Blue 600 | #2563EB | Links, highlights, interactive accents |
| Blue 500 | #3B82F6 | Secondary accent |
| Blue 50 | #EFF6FF | Soft accent backgrounds |
| Slate 600 | #526176 | Body text |
| Slate 400 | #8A96A8 | Secondary metadata |
| Slate 200 | #DCE3EC | Borders |
| Slate 100 | #EEF2F7 | Subtle backgrounds |
| White | #FFFFFF | Main surfaces |

## Usage rules
Use Ink for high-importance text and dark sections. Use Blue 600 sparingly for actions and meaningful emphasis. Keep body copy on white or very light neutral backgrounds. Borders should remain subtle. Do not use every accent color at once.

## Accessibility
Text and interactive elements must maintain readable contrast. Color must not be the only signal for status or meaning.
